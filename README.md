"# Building Management System

A full-stack building management system designed with a modern TypeScript ecosystem.

## Technology Stack

### Frontend

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Query
- React Hook Form
- Zod

### Backend

- NestJS
- TypeScript
- Prisma
- PostgreSQL
- Redis
- BullMQ

### Authentication

- JWT
- Refresh tokens
- Argon2

### Testing

- Jest
- Supertest
- Playwright

### Infrastructure

- Docker
- Docker Compose
- GitHub Actions

### Storage

- S3 / Cloudinary

### Payments

- Razorpay

## Deployment

- **Frontend:** Vercel
- **Backend:** Render / AWS / Railway
- **Database:** Neon PostgreSQL
- **Redis:** Upstash / Redis"
